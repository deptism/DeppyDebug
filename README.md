DeppyDebug (formerly DeptismHUD) is a UI mod designed for H-Slice engine, which is in https://mega.nz/file/tWQiRBLa#dHv3N0ENXgg16EZYfD7QHgQOA5-uJK3UQsfnMjZtVBg (im devastated that H-Slice's official github page was deleted by AndreNicholasJr, why wahhhhh)
--------------------------------------------------------------------------
HOW TO PUT THE MOD INTO THE ENGINE:
1. Download the .zip
2. Extract the .zip folder
3. Drag it to H-Slice/mods (THE MOD IS GLOBAL BECAUSE OF "runsGlobally: true," IN THE pack.json)
--------------------------------------------------------------------------
This HUD includes:
- Song info and progress (BPM, Sections, etc...)
- A side note count, just like JSEngine before v1.49.0!
- BPS, MPS,...
- More unused and legacy scripts that is apart of the "UNUSED" folder of the HUD addon.
